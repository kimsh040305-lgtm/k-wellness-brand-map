# K-웰니스 브랜드 맵

**웰니스 브랜드들은 누구를 잡고, 무엇으로 성장했나?**

한국 애슬레저·짐웨어 브랜드 6개(본투윈, 젝시믹스, 안다르, 뮬라웨어, HDEX, 압도)의 고객층, 가격, 성장 계기를 공개 데이터로 비교한 Streamlit 대시보드입니다.

## 데이터
- 네이버 데이터랩 검색어 트렌드 (2016.01–2026.10, 성별·연령)
- 무신사 브랜드 상품 목록 (2026.11.25, 77개 상품)
- 공시 인용 기사·증권사 리포트 매출 (2018–2025)
- 언론 보도 기반 브랜드 이벤트 40건
- 문화체육관광부 국민생활체육조사 (2019–2025)

## 실행
```bash
pip install -r requirements.txt
python prep.py        # data/ 원자료 → data/processed/
streamlit run app.py
```

브랜드 로고는 각 브랜드의 상표이며, 학습·포트폴리오 목적의 식별 용도로만 사용했습니다.
